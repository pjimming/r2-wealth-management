# 招行 R2 最新产品与数据来源

## 先说结论

这个技能不登录招商银行账户，也不抓取账户数据或实时额度。它可以调用招行公开的统一查询平台和移动端货架来筛选、更新产品池；但实时额度、实际可买、赎回 T+n 仍只能在 App 确认。

最新额度、可买状态、区域额度和账户起购金额，只能在招商银行 App 登录后确认。公开网页、公众号和社交平台只能作为线索，不能替代购买当天的 App 核验。

## 来源优先级

| 优先级 | 来源 | 能拿到什么 | 注意 |
|---:|---|---|---|
| 1 | 招商银行 App → 理财/产品货架/新品/额度 | 实时额度、可买状态、起购、费率、交易规则、订单入口 | 地区/账户差异大；购买当天重新看 |
| 2 | 招银理财官网、招银理财微信公众号 | 新发公告、产品说明书、费率/经理/规模/开放公告 | 适合核对发行方和产品公告 |
| 3 | 中国理财网 `www.chinawealth.com.cn` | 产品登记编码、发行机构、风险等级、产品类型 | 用来防止代码错、产品假、风险等级误判 |
| 4 | 招商银行官网/网点公告 | 代销公告、节假日交易安排、系统维护、额度调整 | 节前尤其要看 |
| 5 | 小红书、群聊、博主截图 | 新发线索、额度经验、抢购节奏 | 只能当线索，不能作为最终依据 |

## 公开接口与自动快照（2026-10-19 已验证）

统一查询平台接口：

```text
POST https://finprod.paas.cmbchina.com/api/prod/queryProdList
```

按截图条件查询：`type=PN`、`isOwn=C`（代销）、`isPublic=Z`（不限）、`status=1`（开放中）、`riskLevel=R2`、`crossFinance=Z`。2026-10-19 实测返回 980 只 R2 开放代销产品，20 页 × 50 条。

关键字段：

- `pastPerf.tqilstw4z3`：A/B/C/D/F = 1M/3M/6M/1Y/成立以来
- `zbasPrf`：业绩比较基准
- `zchrCst + chrmn2 + chrsal`：托管 + 固定管理 + 销售服务费
- `buynfq`：起购金额
- `begdat`：下一开放日
- `statusText=1`：开放中

本工作区主脚本是 `scripts/fetch-cmb-r2-all.cjs`：从公开接口拉取全量 R2 开放代销池，生成 `data/cmb_r2_all-YYYY-MM-DD.csv`（原始全量）、`data/cmb_r2_universe-YYYY-MM-DD.csv`（普通可买候选池）和 `data/cmb_r2_selected-YYYY-MM-DD.csv`（短/中/长每桶最多 3 只的研究观察池），再调用 `/api/products/refresh`。旧脚本 `scripts/fetch-cmb-r2-snapshot.cjs` 仅保留兼容，不再作为默认更新路径。它不登录账户、不抓实时额度、不替用户下单。详细字段映射、签名捕获、快照选择和观察池评分见 [CMB automation](cmb-automation.md)。

2026-10-19 当前快照：全量 980 只；普通可买候选 432 只（日开 17、短 159、中 93、长 163）；研究观察池 9 只，1Y 中位约 2.72%。全池 1Y 中位约 1.73%。研究观察池只用于研究排序，不是资金分配结果。

“刷新快照”不是抓实时数据，而是重新选择本地 CSV：`R2_PRODUCT_CSV` 优先；否则按**文件名日期**选最新的 `data/cmb_r2_universe*.csv`，找不到时回退 `data/cmb_r2_products*.csv`，同日期看修改时间；然后整表替换 `products`。页面上的 `product_snapshot_date` 是产品 `data_date` 的最大值，不等于文件名日期。

应用观察池的排序不是 CSV 的 `score` 列，而是基于期限调整参考年化。期限桶和权重为：

```text
cash:   1M 70% + 3M 30%（只展示）
short:  1M 20% + 3M 50% + 6M 30%
medium: 3M 50% + 6M 30% + 1Y 20%
long:   3M 20% + 6M 40% + 1Y 40%
```

只在所属桶的可用窗口内重归一化；全部缺失时为 unavailable，不按 0 补齐。若 `1M < 3M - 0.5`，short/medium/long 再扣 0.08。`selection_score` 的前视扣分采用 B 方案：short/medium 阈值 1pp，long 阈值 1.5pp；成立满 18/24 个月分别加 0.015/0.03。`weighted_yield_pct` 是参考年化别名。`cmb_r2_selected` 取 short/medium/long 每桶前 3 只，最多 9 只，cash 不进入。

实际 `watchlist` 不是每桶固定一只：`buildProductView` 会按本金、已确认持仓、待确认买入、期限桶目标、流动性下限、未来 0–3/3–6/6–12 个月现金流、单只/底层策略上限和逐只额度，动态决定产品数量与目标金额。发行方名称和当前持仓占比只展示，不参与筛选或配置限制。

## 招商银行 App 里的常见路径

不同版本会调整入口，以下是常见路径，以当前 App 为准：

- **理财频道 → 产品货架/新品专区/额度专区**：看当日可买、起购、期限、额度；
- **搜索框 → 产品代码/名称**：直接定位产品，避免同名混淆；
- **产品详情 → 交易规则**：买入截止、确认 T+n、赎回截止、到账 T+n、最短持有；
- **产品详情 → 产品说明书/风险揭示书/产品费用**：底层、估值、费率、A/PB 份额；
- **我的 → 持仓/交易记录**：订单号、确认日、起息日、到期/开放日；
- **消息/公告**：新发、额度调整、节假日交易安排。

## 每周/每日更新流程

### 周一：自动生成并核对产品池

- 运行或确认 `scripts/fetch-cmb-r2-all.cjs` 已生成最新的 `cmb_r2_all`、`cmb_r2_universe`、`cmb_r2_selected` CSV；
- 看招银理财公众号/官网的新发预告；
- 在招商银行 App 看本周新品、额度日历、起购金额；
- 对新增候选补 `source`、`data_date` 和说明书核验。

### 买入日 08:50：确认当天状态

- App 搜产品代码/名称，确认在售、额度、起购、费率；
- 看是否“关门/暂停销售/额度已满”；
- 看买入截止、确认日、起息日、赎回到账；
- 不用昨天的截图，不用别人转发的额度图。

### 买入当天：二次核验

1. 产品代码、名称、发行方一致；
2. 风险等级仍是 R2/PR2；
3. 产品说明书/风险揭示书可打开；
4. 费率、份额类别、赎回规则没变；
5. 额度时间和额度金额与 App 一致；
6. 保存订单号、确认日、起息日、到期/开放日截图。

### 收盘后：记录

- 更新 `data_date` 和 `source`；
- 记录额度命中/未命中、实际买入金额；
- 周复盘时删除过期额度和已关门产品。

## 产品池字段与来源对应

| 字段 | 去哪里拿 |
|---|---|
| `name` / `code` | 招商银行 App + 中国理财网 |
| `issuer` | 产品说明书 + 中国理财网 |
| `risk_level` | 风险揭示书 + 中国理财网 |
| `term_days` / `open_rule` | 产品页“交易规则” |
| `purchase_cutoff` / `confirm` | 交易规则 |
| `redeem_cutoff` / `arrival` | 交易规则 |
| `valuation` / `benchmark` / `underlying` | 产品说明书、季报 |
| `fees` / `share_class` | 产品说明书“产品费用”表 |
| `quota_window` | App 当天额度页 + 官方公告 |
| `return_7d/30d/90d` | 官方净值/历史业绩 |
| `max_drawdown` / `negative_days` | 用官方净值序列自算 |
| `source` / `data_date` | 自己记录，必须可追溯 |

## 搜索与核验关键词

如果当前环境有浏览/搜索工具，可以用这些查询找公开信息：

```text
site:cmbchina.com 招银理财 <产品代码>
site:cmbchina.com 招银理财 新品 <年月>
site:chinawealth.com.cn <产品代码>
招银理财 公众号 <产品名称> 说明书
招商银行 理财 节假日 交易安排 <年份>
```

搜索引擎可能滞后；找到后仍要回到 App/官网/中国理财网核对。不要用搜索摘要代替产品说明书。

## 什么算“最新”

- `data_date` 是你核对数据的日期，不是产品成立日；
- 额度和收益率只在当天有效，购买当天必须重看；
- 额度/收益率数据超过 7 天，标记为“过期”，重新核对；
- 来源是社交平台时，标记“仅线索”，直到官方来源确认；
- 产品代码、风险等级、费率、赎回规则任一变化，整行重新核验。

## 新产品的核验清单

1. 招商银行 App 搜代码/名称：在售？有额度？起购多少？
2. 中国理财网查登记编码：发行方、风险等级、产品类型是否一致？
3. 产品说明书：底层、估值、费率、赎回规则是否看得懂？
4. 交易规则：买入截止、确认 T+n、赎回截止、到账 T+n？
5. 官方公告：新发、额度、节假日安排有没有变化？
6. 产品池：写入 `source` 和 `data_date`，再进入评分。

## 不能做的事

- 不绕过登录、验证码、风控或地区限制；
- 不抓取用户账户数据，不代用户下单；
- 不使用“内部额度”“代抢”“保过”等非官方渠道；
- 不把博主截图、群聊转发当成最终数据；
- 不承诺实时性。额度是地区、账户、时间特定的，公开信息只能辅助判断。

## 技能能做什么

- 调用公开接口生成/更新 R2 产品快照，并扫描更大的 R2 开放池；
- 解释快照文件选择、观察池评分和刷新逻辑；
- 帮你把公开信息和 App 截图整理成结构化产品池；
- 按 R2、期限、费率、回撤、流动性、额度做筛选和评分；
- 帮你算配置、切换盈亏平衡和月度复盘；
- 提醒你哪些字段还没核验、哪些数据已经过期。

登录后的实时额度和最终下单，必须由你在招商银行 App 里确认。
