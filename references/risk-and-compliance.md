# 风险与边界

## R2 不等于保本

R2/PR2 是银行理财的风险等级，不是存款，也不受存款保险保障。净值型 R2 产品会出现：

- 单日“挂 0”或负收益；
- 月度收益低于预期；
- 债市调整时净值回撤；
- 赎回规则、额度、费率变化；
- 极端情况下的流动性限制。

任何“保本”“稳赚”“年化 X% 保证”“内部额度”的说法，都要先当成风险信号。

## 3% 目标是目标，不是承诺

年化 3% 是技能里的默认目标，不是 R2 的固有收益，也不是保本保收益承诺。当前开放式 R2 产品可能只有 1.3%–2.2%；达不到 3% 时，要明确说缺口，不能用杠杆、假收益、信用下沉到不适合的级别，或把短期高收益年化当成全年收益。

为了接近 3% 而延长锁仓、增加信用暴露或接受更大回撤，必须由用户明确同意，并同时设定回撤和流动性上限。

## 不做的四件事

1. **不借钱买理财**：不用消费贷、信用贷、信用卡、经营贷或向亲友借款来放大本金。
2. **不满仓一只**：单只产品有发行方、策略、期限和额度风险；上限见配置文件。
3. **不把应急金锁死**：6–12 个月必要支出放在这个 R2 组合之外的活期/存款/独立现金账户，不进入长期限产品。组合内可以 0 现金，但组合外必须有应急金。
4. **不替用户下单**：技能提供筛选、计算和检查清单；最终买卖由用户确认和执行。

## 主要风险

| 风险 | 表现 | 应对 |
|---|---|---|
| 净值波动 | 单日/单周负收益 | 看月/季趋势，不追涨杀跌 |
| 流动性 | 赎回到账慢、限额、暂停赎回 | 现金流匹配，保留短桶或可选 R2 流动性仓 |
| 集中度 | 单只/单系列/单策略占比过高 | 单只 25–30%；多银行发行方 40–50%；单一银行用系列/底层策略上限 |
| 发行方/投研 | 同系列产品持续跑输 | 同期限横向比较，分散发行方 |
| 费率 | 管理费、销售费、业绩报酬吃掉收益 | 看产品费用表，比较 A/PB 份额 |
| 额度 | 买不到、额度临时变化 | 准备替代品，不追劣质替代 |
| 信息 | 截图过期、代码错误、软广 | 以说明书/公告/App 为准 |
| 诈骗 | 假 App、假客服、代抢、内部通道 | 只用官方渠道，不转账给个人 |
| 数据隐私 | 账号、余额、身份证、验证码泄露 | 不把敏感信息发给第三方 |

## 内容与商业合作

社交平台上的理财内容可能有广告、返佣、导流或软性合作。看到“某产品很好”“某额度很难抢”时：

- 先核对产品代码、风险等级、说明书和官方公告；
- 区分“信息整理”和“买入建议”；
- 不因为博主晒了收益就跟单；
- 不把过往收益当成未来收益；
- 不把“额度稀缺”当成“安全”。

## 适合与不适合

更适合：

- 有一笔 6–12 个月以上不用的闲钱；
- 能接受 R2 净值波动；
- 愿意花时间核对规则、记录数据；
- 目标是稳健现金流，不是高收益。

不适合：

- 应急金不足（组合内可以 0 现金，但组合外必须有）；
- 短期要用钱；
- 不能接受任何负收益；
- 目标 3% 但不愿承担更长锁仓或更大回撤；
- 想靠理财快速致富；
- 没有时间核对额度和规则，只能听消息买入。

## 如果产品出现亏损

1. 先看是市场波动、净值更新、还是产品规则/底层发生变化。
2. 对比同期限、同类型产品的回撤，不要只看自己的绝对亏损。
3. 检查是否触发自己的回撤上限、流动性红线或集中度上限。
4. 不要因为亏损就盲目加仓摊平；R2 也会有色差和信用风险。
5. 如果决定赎回，先算到账时间和替代产品，不要“先卖再找”。

## 表达边界

在输出中：

- 说“通过筛选”“符合某桶”“在假设 A/B/C 下更合适”，不说“必赚”“稳赚”“保证收益”；
- 给区间和条件，不给单点承诺；
- 明确数据日期和来源；
- 对缺失数据说“未验证”，不要编造；
- 涉及具体买卖时，给出决策清单和风险，不替用户做最终决定；
- 不执行转账、下单、赎回等资金操作，除非用户明确要求且环境支持，并再次确认金额、产品和风险。
